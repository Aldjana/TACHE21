# Hotel PMS Frontend

Système de gestion hôtelière (Property Management System) - Frontend

## Description

Application web moderne pour la gestion hôtelière avec React, Vite et Tailwind CSS.

## Fonctionnalités

- Gestion des réservations
- Gestion des chambres
- Gestion des clients
- Suivi des paiements
- Dashboard avec statistiques
- Interface responsive (mobile, tablette, desktop)

## Technologies

- React 18
- Vite
- Tailwind CSS
- React Router
- Lucide Icons

## Installation

```bash
npm install
```

## Démarrage

```bash
npm run dev
```

## Build

```bash
npm run build
```

## Configuration

Créer un fichier `.env` à la racine du projet :

```
VITE_API_URL=http://localhost:3000/api
VITE_API_BASE_URL=http://localhost:3000
VITE_ENV=development
```
